# Sales-Performance-Dashboard
Developed an interactive Sales Performance Dashboard using Power BI to analyze sales, profit, and order trends across different regions. Used data cleaning, R, and interactive visualizations to identify business insights and support data-driven decision-making. 📌 **Project Overview**

This project focuses on analyzing sales performance using an interactive Power BI dashboard. The goal is to transform sales data into meaningful business insights by tracking revenue, profit, orders, and regional performance.

🎯 **Project Objectives**

Analyze overall sales and profitability.

Identify top-performing regions and product categories.

Monitor key business performance indicators (KPIs).

Discover sales trends and business opportunities.

Support data-driven decision-making.

🛠️** Tools & Technologies**

Power BI – Dashboard development and visualization.

R – Data cleaning and analysis.

Data Analysis – Identifying trends and patterns.

📈 **Key KPIs**

Total Sales

Total Profit

Total Orders

🔍 **Key Insights**

The West region generated the highest profit.

The Technology category contributed the highest revenue.

Interactive filters allow users to explore sales performance across different regions and categories.

📊 **Dashboard Features**

Interactive charts and visualizations.

Region and category filters.

Sales and profit performance tracking.

Business-focused KPI reporting.

Easy-to-understand dashboard layout.
